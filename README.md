# 이미지 인식 마우스 매크로

화면에서 지정한 이미지를 찾아 순서대로 클릭하는 Windows용 매크로입니다. (.NET 8 WinForms, 단일 exe)

## 다운로드

https://github.com/dawnlordroid/mouse-macro/releases

최신 릴리스의 `MouseMacro.exe`를 받아 실행하세요. (.NET 설치 불필요)

> **참고:** 일부 프로그램(게임, 관리자 권한으로 실행된 프로그램 등)은 일반 권한의 클릭을 무시합니다. 이 경우 `MouseMacro.exe`를 **관리자 권한으로 실행**해야 클릭이 적용됩니다.

## 사용법

1. 목록에 클릭할 이미지를 **추가**합니다. `▲` `▼`로 순서를 바꾸고 **삭제**로 제거합니다.
   - 첫 번째 항목은 기본으로 `samples/doomyeon-sayong.png`("도면 사용" 칸)가 들어 있습니다.
2. 항목마다 **클릭 위치**를 정합니다.
   - 이미지 전체 중심 / 위쪽 정사각형 중심 / 직접 지정(X, Y)
   - 이미지 미리보기를 클릭하면 그 지점이 클릭 위치(이미지 좌상단 기준 오프셋)로 지정됩니다.
   - "도면 사용" 이미지는 전체 이미지를 인식하되 위쪽 네모칸의 중심을 클릭합니다.
3. 항목마다 **대기 시간(ms)**(이미지가 나타날 때까지 기다리는 최대 시간)과 **못 찾으면 중지** 여부를 정합니다.
4. 공통 설정: **일치율(%)**, **클릭 후 대기(ms)**, **반복(0=무한)**.
5. **시작**을 누르면 모든 모니터를 캡처해 이미지를 찾고, 찾으면 클릭한 뒤 설정한 시간만큼 대기하고 다음 이미지로 넘어갑니다.
6. 오른쪽 화면에 캡처 미리보기와 찾은 영역(사각형), 아래 로그에 성공/실패, 일치율, 클릭 좌표가 표시됩니다.
7. **중지** 버튼 또는 전역 단축키 **F12**로 언제든 즉시 중지할 수 있습니다.
8. **저장** / **불러오기**로 순서와 설정을 JSON 파일로 저장하거나 불러옵니다.

## 빌드

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

`main`에 푸시하면 GitHub Actions가 빌드해서 Releases에 `MouseMacro.exe`를 올립니다.
