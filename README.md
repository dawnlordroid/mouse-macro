# 좌표 클릭 마우스 매크로

고정된 좌표를 순서대로 클릭하는 Windows용 매크로입니다. (.NET 8 WinForms, 단일 exe)

## 다운로드

https://github.com/dawnlordroid/mouse-macro/releases

최신 릴리스의 `MouseMacro.exe`를 받아 실행하세요. (.NET 설치 불필요)

> **참고:** 일부 게임이나 관리자 권한으로 실행된 프로그램은 일반 권한의 클릭을 무시합니다. 이 경우 `MouseMacro.exe`를 **관리자 권한으로 실행**해야 클릭이 적용됩니다.

## 기본 순서 (기준 해상도 2560x1440, 게임은 선택한 모니터)

모든 클릭 사이 대기는 1000ms입니다.

1. (176, 758) 클릭: "도면 사용" 칸
2. (702, 1105) 클릭: 종이 4장 중 왼쪽에서 3번째 종이
3. (2250, 1263) 클릭: "주문 확인" (오른쪽 아래)
4. **확인 단계**: 영역 x 1405..1485, y 1050..1095 ("인도까지 남은 시간: 28일"의 숫자+"일")을 기준 이미지(28일)와 비교
   - 일치하면 5번으로 진행
   - 일치하지 않으면(다른 숫자이거나 화면이 안 뜸) **"28일이 아님 → 중지"** 로그(유사도 표시), 알림음, 메시지 박스를 띄우고 매크로를 중지
   - 판정 전에 250ms마다 최대 타임아웃(기본 5초) 동안 재시도
5. (1285, 1258) 클릭: "주문 취소"
6. (1472, 833) 클릭: 팝업("건조 비용 환불")의 "확인" → 첫 화면으로 돌아가 1번부터 반복

반복 횟수 기본값 0 = 무한 반복(4번이 실패하거나 사용자가 중지할 때까지). **최대 반복**(기본 0 = 무제한)으로 안전장치를 둘 수 있고, 로그에 회차가 표시됩니다.

## 기준 캡처 (28일 이미지)

1. 매크로를 **중지**합니다.
2. 게임을 "인도까지 남은 시간: 28일"이 보이는 화면으로 둡니다.
3. **기준 캡처** 버튼을 누릅니다. 확인 영역이 현재 화면에서 캡처되어 `%AppData%\MouseMacro\ref_28.png`로 저장되고 실행 시 자동으로 로드됩니다. (기준/최근 캡처 미리보기가 창에 표시됩니다.)
4. 확인 단계가 있는데 기준 이미지가 없으면 시작이 거부됩니다("먼저 기준 캡처를 하세요").

비교는 회색조 정규화 상호상관(NCC)이라 팝업으로 화면이 약간 어두워져도 견딥니다. **유사도 임계값**(기본 0.90)과 **확인 타임아웃**은 UI에서 바꿀 수 있고, 확인 영역(X, Y, W, H, 기준 해상도 기준)은 목록에서 직접 수정합니다.

## 사용법

1. **모니터**를 고릅니다(주 모니터 표시됨). 기본적으로 "선택한 모니터 좌상단 기준 좌표"가 켜져 있어 클릭 위치 = 모니터 좌상단 + (X, Y)입니다.
2. **기준 해상도**(기본 2560x1440)와 모니터 해상도가 다르면 좌표가 비율대로 보정됩니다. 끄려면 "해상도 비율 보정"을 해제하세요.
3. 목록에서 단계를 **추가/삭제**, `▲` `▼`로 순서 변경, 셀을 직접 수정합니다. 각 단계는 종류(Click/Check), X, Y, W/H(확인 영역), 버튼(Left/Right), 이후 대기(ms), 메모로 구성됩니다.
4. 설정: **반복(0=무한)**, **최대 반복**, **시작 전 대기(초)**(기본 3초, 그 사이 게임 창으로 전환), **대기 랜덤 ±(ms)**(기본 0).
5. **시작**(또는 F10 토글)으로 실행하고 **중지** 또는 전역 단축키 **F12**로 언제든 즉시 중지합니다. 로그에 단계별 실제 클릭 좌표가 표시됩니다.
6. **저장** / **불러오기**로 JSON 파일을 다루며, 종료 시 마지막 설정이 자동 저장되어 다음 실행 때 자동으로 불러옵니다(`%AppData%\MouseMacro\config.json`).

## F8로 좌표 미세 조정

1. 목록에서 수정할 단계를 선택합니다.
2. 마우스를 게임 화면의 목표 위치에 올리고 **F8**(또는 "좌표 캡처" 버튼)을 누르면 모니터 기준·기준해상도로 환산된 좌표가 선택한 단계에 입력됩니다.
3. "테스트 클릭 (이동만)" 버튼은 클릭 없이 커서만 해당 단계 위치로 옮겨 확인합니다.
4. 창 위쪽의 라벨에 현재 마우스 위치(절대/모니터 기준)가 실시간으로 표시됩니다.

## 빌드

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

`main`에 푸시하면 GitHub Actions가 빌드해서 Releases에 `MouseMacro.exe`를 올립니다.
